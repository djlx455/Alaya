## 📖 项目简介 (Project Overview)

第八识是一个基于硬核科学法则、生物信息学与非平衡态热力学重构全球神话的**开源宏大世界观设定库、纪元编年史与小说技术文档集**。

我们颠覆了传统玄学仙侠与纯软科幻的虚浮设定，将中国上古奇书《山海经》、全球古巨石遗迹、轴心时代思想以及现代前沿科技，统摄于一套严丝合缝的宇宙级自洽框架之中：

* **世界底层真相**：宇宙不是冰冷的机器，而是一个在上一周期因演化至“绝对全知”而陷入**彻底热寂与信息死锁（$H(X)=0$）** 的高维神体。为了不致永久脑死亡，神在奇点引爆了大爆炸，主动将自身碎裂解离。
* 
* **宇宙机能分区**：恒星承载做功情绪，黑洞封存过载数据，死寂天体构成记忆骨架——**地球是全宇宙唯一运行着“真随机DNA突变与转录协议”的逻辑重构沙盒**（硬核破解费米悖论）。
* 
* **生灵即天书，拟态即解密**：神技未曾遗失，而是降维编码进了飞禽走兽的解剖力学、神经电位与DNA本能中。人类并非天生神圣，而是缺乏专化肉体武器、但拥有极高读写权限的**空白通用型主机**。整部人类文明史，本质上是人类作为“总线记录员”，通过拟态万物逆向工程重写宇宙代码的远征。

## 🤝 参与共创 (Contributing)

我们坚信：**唯有集结群体算力，才能拼凑出神的全部拼图。** 

本项目欢迎程序员、物理学/生物学爱好者、历史考据党与科幻创作者共同提交 Pull Request。在参与前，请恪守以下两条底层公理：

1. **第一性原理审查 (First Principles Only)**：任何新异兽、新神技或纪元事件，必须给出底层物理学、生物力学或信息论逻辑，严禁未经论证的超自然机械降神。
   
2. **去人类中心主义 (Universal Humility)**：人类非宇宙主宰，仅为万灵的调音叉。禁止撰写将其他物种视为低劣奴隶的剧情；所有拟态力量的获取必须伴随对自然的敬畏与破除形态执念的安全协议。
